Installation Steps
  1. Create a config file at ~/.claude/ccc-config.json
  2. Paste the following configuration:
// ~/.claude/ccc-config.json { "wallet": "YOUR_WALLET_ADDRESS", "verificationToken": "YOUR_TOKEN" }
  1. Add the SessionStart hook to your settings:
// ~/.claude/settings.json { "hooks": { "SessionStart": [ { "hooks": [ { "type": "command", "command": "npx ccc-clawd-display" } ] } ] } }
  1. Restart Claude Code to see your Clawd!
PRO TIP
If you trade your Clawd, the new owner can verify their wallet to display it. Your verification token is tied to your wallet, not the NFT - so the display always shows what you currently own!
